# Smriti on Windows — installed app (wireless)

The installer gives you a standalone Smriti: its own Python runtime, its own
TeX (TinyTeX), its own SSH key. Nothing goes on PATH, no admin rights, and
other apps (Hermes, Claude Code, your `~/.ssh`, MiKTeX) are not touched. It is
for **cable-free** use: tailnet or Wi-Fi/hotspot, no USB route.

## Install

Run `Smriti-Setup-<version>.exe` (per-user, no UAC prompt). It installs to
`%LOCALAPPDATA%\Programs\Smriti` and adds Start Menu entries:

| Entry | What |
|---|---|
| **Smriti** | `SmritiTray.exe` — the notification-area app (Windows Search finds it) |
| **Smriti Console** | a cmd window in the app folder, so `smriti <switch>` works |
| Uninstall Smriti | removes the app; asks before deleting your data (default: keep) |

Optional tasks: desktop shortcut, start with Windows (both off by default;
the tray's *Settings > Start with Windows* toggles the latter later).

## First run (Smriti Console)

```
smriti pair <tablet-ip-or-magicdns>  # one-time: Smriti SSH key -> tablet (types root password once)
smriti link set-wifi 172.20.10.2 # tablet IPv4 on Wi-Fi / iPhone hotspot (changes per network)
smriti auth login chatgpt        # or: auth login claude / auth key set openai|anthropic|local
smriti link-test                 # PASS/FAIL per route
smriti doctor                    # whole chain, each FAIL with its fix
```

Then *Smriti* tray > **Start**. **Stop** and **Quit** disarm the tablet and
verify it (armed=0, stream inactive) *before* stopping the daemon; if that
can't be verified the daemon keeps running and a notification says so
(*Force stop* / *Force quit* appear for that case).

## Switches (`smriti.exe`)

| Switch | |
|---|---|
| *(none)*, `tray` | tray (no args hands off to `SmritiTray.exe`) |
| `run` | daemon in the foreground (Ctrl+C to stop — disarm the tablet yourself first) |
| `doctor [host]` | every link pen -> reply, with fixes |
| `link-test` | probe each route, read-only |
| `link show` / `link set-wifi <ipv4>` / `link set-tailnet <ip-or-magicdns>` | routes |
| `pair <tablet-ip> [--no-save]` | install Smriti's key; saves the address as tailnet (100.64/10) or wifi |
| `deps` | resolved python / pdflatex / ssh / key / claude / data dir; exit 1 if pdflatex or ssh missing |
| `deps set pdflatex\|ssh\|claude <path>` | use an existing installation (`""` resets to default) |
| `tex-test` | compile an equation, a circuitikz and a pgfplots snippet, with timings |
| `auth ...` | sign-in, API keys, endpoints (local / ChatGPT / Claude): `smriti auth --help` |
| `paths`, `version` | where things live / version |

## Where things live

* App (read-only): `%LOCALAPPDATA%\Programs\Smriti` — `_internal\config.toml`
  (shipped defaults), `_internal\tinytex\` (TeX), `_internal\assets\smriti.ico`.
* Your data: `%LOCALAPPDATA%\Smriti` (or `SMRITI_HOME`) — `config.toml`
  (your overrides; tray *Settings > Edit config*), `credentials.bin`,
  `ssh\id_ed25519` + `ssh\known_hosts`, `logs\daemon-YYYYMMDD.log`,
  `state\`, `sessions\`, `texmf-var\` (TeX caches).

## Dependency resolution

* **pdflatex**: `[tex] pdflatex` (your MiKTeX/TeX Live via `deps set`) >
  `SMRITI_PDFLATEX` > bundled TinyTeX. The installed app never silently uses a
  TeX from PATH. Bundled TeX runs with `TEXMFVAR/TEXMFCONFIG/TEXMFHOME` under
  your Smriti data folder.
* **ssh**: `[ssh] ssh_bin` > `C:\Windows\System32\OpenSSH\ssh.exe` > PATH,
  always with `-F none`, Smriti's key and known_hosts (never `~/.ssh`).
  Needs Windows' *OpenSSH Client* optional feature (on by default in Win 10/11).
* **claude**: `[claude] claude_bin` > PATH (only needed for Claude-subscription routes).
* Dev checkouts (repo, no `SMRITI_HOME`, no Smriti key) keep plain `ssh` +
  `~/.ssh/config` and PATH TeX, exactly as before.

Note: if the tablet runs **Tailscale SSH**, tailnet logins succeed with
Tailscale identity (`none` auth) even before pairing; Wi-Fi/hotspot routes go
to the tablet's own sshd and need `smriti pair`.

## Build (developer)

```
bash packaging/build.sh
```
Runs focused tests, makes the placeholder icon if missing, checks/fetches
TinyTeX (`build/vendor/TinyTeX`; clean machine: pinned
`TinyTeX-1-windows-v2026.10.exe` unpacked with 7-Zip) and installs the TeX
packages the template needs (standalone, circuitikz, pgfplots, preview, ...),
then PyInstaller (`packaging/smriti.spec`: one onedir, `smriti.exe` console +
`SmritiTray.exe` windowed) and Inno Setup (`packaging/smriti.iss`) ->
`dist/installer/Smriti-Setup-<version>.exe`. Version = `VERSION` in `host/app.py`.

## Mascot

The tray/installer icon is `packaging/assets/smriti.ico` (placeholder eye,
generated by `host/tray.py:write_ico`). To switch to the ermine mascot, replace
that file with a multi-size .ico of the same name and rebuild — nothing else
changes.
